# Docker Container Access

Quick commands for `devcontainer-frappe-1`.

## Quick Access

### Check Status
```bash
docker ps --format "table {{.ID}}\t{{.Names}}\t{{.Status}}\t{{.Ports}}" | grep -E "CONTAINER ID|frappe|bench|dcnet"
```

### Access Shell
```bash
# As frappe user (recommended)
docker exec -it -u frappe devcontainer-frappe-1 bash

# As root
docker exec -it devcontainer-frappe-1 bash
```

## Common Commands

**Note:** Bench path is `/workspace/development/frappe-bench`

### Bench Commands (from host - non-interactive)

**Version & Info:**
```bash
# List all sites
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench list-sites"

# Check version of all apps
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench version"

# List installed apps
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench list-apps"
```

**Database & Migrations:**
```bash
# Migrate database (run patches, sync schema)
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench migrate"

# Backup site (saved to sites/{site}/private/backups/)
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench backup"

# Backup all sites
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench backup-all-sites"
```

**Development:**
```bash
# Clear cache
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench clear-cache"

# Build assets (JS/CSS)
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench build"

# Update bench (pull changes, apply patches, build assets)
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench update --no-backup"

# Update only code (no migrations/build)
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench update --pull"
```

**App Management:**
```bash
# Install app on site
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench --site flow.local install-app dcnet_apps"

# Uninstall app from site
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench --site flow.local uninstall-app dcnet_apps"
```

**Scheduler:**
```bash
# Enable scheduler
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench enable-scheduler"

# Check background workers
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench doctor"

# View pending jobs
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench show-pending-jobs"
```

**Site Admin:**
```bash
# Reset admin password
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench --site flow.local set-admin-password [new_password]"

# Destroy all sessions
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && bench destroy-all-sessions"
```

### Interactive Commands (inside container)
```bash
# Access shell first
docker exec -it -u frappe devcontainer-frappe-1 bash

# Then run commands inside:
cd /workspace/development/frappe-bench
bench start
bench console
bench mariadb
```

### View Logs
```bash
# Container logs
docker logs devcontainer-frappe-1 --tail 100 -f

# Bench logs
docker exec -u frappe devcontainer-frappe-1 bash -c "cd /workspace/development/frappe-bench && tail -f logs/*.log"
```

### Container Management
```bash
# Restart
docker restart devcontainer-frappe-1

# Stop/Start
docker stop devcontainer-frappe-1
docker start devcontainer-frappe-1

# Stats
docker stats devcontainer-frappe-1 --no-stream
```

## Container Info

- **Name:** `devcontainer-frappe-1`
- **User:** `frappe` (UID 1000)
- **Bench Path:** `/workspace/development/frappe-bench` (NOT `~/frappe-bench`)
- **Ports:** 8000-8005 (web), 9000-9005 (socketio)

## Important Notes

- Use `-it` flags ONLY for interactive shell access
- For scripted commands (from host), use WITHOUT `-it` to avoid TTY errors
- Bench path is `/workspace/development/frappe-bench` (generated by installer.py)
- All bench commands must be run from bench directory

## Quick Bench Reference

| Command | Purpose |
|---------|---------|
| `bench version` | Check app versions |
| `bench migrate` | Run database migrations |
| `bench clear-cache` | Clear all caches |
| `bench build` | Build JS/CSS assets |
| `bench update` | Pull + patch + build |
| `bench backup` | Backup site |
| `bench console` | Python console |
| `bench mariadb` | SQL console |
