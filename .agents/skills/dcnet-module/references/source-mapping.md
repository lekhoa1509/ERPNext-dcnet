## Detection Logic

When user runs `/dcnet-module {STT}` or `/dcnet-ba {STT}` or `/dcnet-mockup {STT}` or `/dcnet-guide {STT}`:

1. Parse arg: extract STT number (e.g., `07`, `33`, `02`)
2. Look up STT in mapping table above → get slug, module name, milestone, company, source, section, ERPNext skill
3. Module folder path: `docs/modules/{STT}-{slug}/` (e.g., `docs/modules/07-kho-hang/`)
4. If STT not found: suggest closest match
5. Also accept `{STT}-{slug}` format for backward compatibility (e.g., `07-kho-hang` → extract STT=07)
