## A1. Thông tin kỹ thuật

| # | Câu hỏi | Ghi chú | Trả lời |
|---|---------|---------|---------|
| 1 | **Size tay** có những loại nào? | VD: S/M/L/XL hay đo theo số (cm)? | |
| 2 | **Đường bóng** có những giá trị nào? | VD: Fade / Draw / Straight / Hook / Slice? | |
| 3 | **Đường cao bóng** có những giá trị nào? | VD: Low / Mid / High? | |
| 4 | **Cấp độ người chơi** ngoài "Người mới / Đã chơi" có level nào khác? | VD: Beginner / Intermediate / Advanced / Pro? | |
| 5 | **Đơn vị đo** sử dụng là gì? | Khoảng cách: yard hay mét? Tốc độ: mph hay km/h? | |
| 6 | **Hình swing** lưu dạng gì? | Text mô tả? Ảnh chụp? Video? | |

## A3. Form đặt lịch Website hiện tại

> **Tham khảo:** https://nhatminhsports.vn/gioi-thieu/fitting-3d-tech/
>
> Form hiện tại có 2 field: **Ngày hẹn** + **Giờ hẹn** (08:00 - 18:00)

| # | Câu hỏi | Lựa chọn | Trả lời |
|---|---------|----------|---------|
| 12 | **Xài lại form đặt lịch** trên website hiện tại không? | ☐ Có, xài lại ☐ Không, build form mới | |
| 13 | Nếu **xài lại** → Cần sync từ web sang CRM như thế nào? | ☐ API realtime ☐ Webhook ☐ Cron job | |
| 14 | Nếu **build mới** → Form nằm ở đâu? | ☐ Tích hợp vào web hiện tại ☐ Subdomain riêng ☐ Trên CRM (public) | |
| 15 | Form cần thêm field nào ngoài Ngày + Giờ? | ☐ Họ tên ☐ SĐT ☐ Email ☐ Ghi chú ☐ Chi nhánh | |
